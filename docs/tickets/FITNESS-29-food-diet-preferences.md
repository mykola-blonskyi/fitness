### Parent

### What to build

### Acceptance criteria

- [x] A user can declare an allergy or exclusion targeting a category, subcategory, role, or a single food item
- [x] A user can declare a diet type (vegetarian/vegan/keto/paleo)
- [x] Preferences can be viewed and removed from a settings screen
