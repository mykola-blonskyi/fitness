# FITNESS-18: Training Program builder

### Parent

FITNESS-2 — Spec: Training Programs & Workout Tracking

### What to build

Let users build a Training Program: ordered exercises with targets, archive/reactivate.

### Acceptance criteria

- [x] A user can create a Training Program with a title
- [x] Exercises can be added to a program in a specific order, with target sets/reps (or duration for cardio-category exercises)
- [x] Exercises within a program can be reordered and removed
- [x] A program can be archived and later reactivated

### Blocked by

#11 Exercise catalog browse/search + manual creation UI
